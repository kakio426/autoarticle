## 📋 개요

### 기능 설명
AutoSchoolArticle의 핵심 가치인 "고품질 기사"와 "아름다운 디자인"을 극대화하기 위한 로드맵입니다. 불필요한 AI 기능(이미지 생성 등)은 배제하고, 선생님이 수정한 내용을 학습하여 스타일을 모사하는 **Style RAG** 기술과, 완벽한 레이아웃을 보장하는 **Dynamic Design Engine** 구축에 집중합니다. 또한 개별 기사를 모아 하나의 디지털 신문으로 발행하는 통합 기능을 목표로 합니다.

### 성공 기준
- [ ] **디자인 무결성**: 1~4장 사진 배치 및 가변 텍스트 길이에 대응하는 PDF/Word 레이아웃이 깨짐 없이 생성됨.
- [ ] **스타일 학습**: 선생님의 수정 내역이 누적될수록 AI가 해당 학교의 어조를 자동으로 학습(RAG).
- [ ] **디지털 신문**: 선택한 3~5개의 기사가 하나의 신문 레이아웃(Grid)으로 자동 조판됨.
- [ ] **보안**: 클라우드 의존 없이 로컬 데이터베이스 암호화 및 안전한 관리.

### 사용자 기대 효과
단순 자동화를 넘어 "디자이너가 작업한 듯한" 고품질 결과물을 제공하며, 쓸수록 학교 스타일에 맞춰지는 개인화된 AI 경험을 제공합니다.

## 🏗️ 아키텍처 결정

| 결정 사항 | 근거 | 트레이드오프 |
|----------|-----------|------------|
| **Local-First Architecture** | 클라우드 보안 우려 해소, 개인정보 로컬 격리 | 기기 간 동기화 불편 (파일 이동 필요) |
| **Advanced Layout Engine** | 기존 FPDF/Docx 단순 나열 방식 탈피, Grid 시스템 도입 | 레이아웃 알고리즘 구현 복잡도 증가 |
| **Feedback Loop RAG** | 별도 파인튜닝 없이 수정 데이터(Correction)를 벡터화하여 활용 | 초기 학습 데이터 쌓일 때까지 성능 체감 미미 |
| **Streamlit Components** | 기본 UI 한계 극복을 위해 Custom HTML/CSS 컴포넌트 적극 활용 | 유지보수 난이도 약간 상승 |

**목표**: 선생님의 "수정 행위"를 학습하여 기사 품질을 학교 전용 스타일로 자동 향상.
**예상 시간**: 15시간
**상태**: ⏳ 대기 중

#### 작업 항목

**🔴 RED: 실패하는 테스트 먼저 작성**
- [ ] **테스트 3.1**: 사용자 수정 데이터 캡처 및 저장 로직 테스트.
- [ ] **테스트 3.2**: RAG 검색 정확도 테스트 ("따뜻한 어조" 요청 시 관련 과거 기사 매칭 여부).

**🟢 GREEN: 테스트 통과를 위한 구현**
- [x] **작업 3.3**: **피드백 루프 시스템**
  - 원본 AI 기사 vs 사용자 최종 수정본(Diff)을 저장하는 로컬 DB 구축.
- [x] **작업 3.4**: **Style RAG 구축 (로컬)**
  - ChromaDB(로컬)를 사용하여 과거 우수 기사(Best Practice) 벡터화.
  - 프롬프트 엔지니어링: "다음과 같은 어휘와 문장 구조를 참고해: [검색된 유사 기사]"
- [ ] **작업 3.5**: **프롬프트 최적화**
  - 단순 생성이 아닌, 학교별 금칙어/선호 단어 반영.

### 단계 4: 디지털 신문 & 보안 (Digital Newspaper)
**목표**: 여러 기사를 모아 하나의 "학교 신문(A4 2~4단 편집)"으로 발행 및 안전한 데이터 관리.
**예상 시간**: 20시간
**상태**: ⏳ 대기 중

#### 작업 항목

- [x] **작업 4.1**: **디지털 신문 편집기 (Aggregator)**
  - 체크박스로 선택한 3~5개 기사를 A4 1페이지(또는 2페이지) 신문 레이아웃에 자동 배치.
  - 헤드라인 기사(크게)와 단신 기사(작게) 구분 알고리즘.
- [ ] **작업 4.2**: **로컬 보안 데이터베이스 (SQLite + 암호화)**
  - CSV를 SQLite로 마이그레이션하여 데이터 무결성 확보.
  - (선택 사항) DB 파일 암호화(SQLCipher)로 개인정보 유출 방지.

#### 품질 게이트 ✋
- [x] **Layout**: 신문 모드에서 기사 간 겹침 로직 오류 0건.

### 단계 5: 수업용 프레젠테이션 (PPT Engine)
**목표**: 작성된 기사와 사진을 활용하여 수업 시간에 바로 사용할 수 있는 PPT 자동 생성.
**예상 시간**: 10시간
**상태**: 🔄 진행 중

#### 작업 항목

- [ ] **작업 5.1**: **PPT 생성 엔진 (`python-pptx`)**
  - 제목 슬라이드 (행사명, 일시, 장소) + 본문 슬라이드 (사진 + 내용) 자동 구성.
  - 긴 본문은 자동으로 2~3장의 슬라이드로 분할.
- [ ] **작업 5.2**: **테마 연동**
  - 선택한 디자인 테마(컬러, 폰트)가 PPT 슬라이드 마스터에도 적용되도록 구현.

#### 품질 게이트 ✋
- [ ] **Visual**: 생성된 PPT를 실행했을 때 이미지 잘림이나 텍스트 넘침 없이 깔끔하게 표시되어야 함.
